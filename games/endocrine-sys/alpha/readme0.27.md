# 人體恆定控制中心 — 內分泌回饋互動（v0.27）

> 教學近似模型（非醫療用途）。本版著重**指標可視化**的易讀性。

## v0.27 更新
- 每張「曲線圖」新增**正常範圍水平虛線**（上下界各一條）。
- 曲線顏色會隨狀態改變：
  - ✅ 正常：綠
  - ⚠️ 偏離：黃（並判斷方向，顯示「偏高 / 偏低」）
  - 🚨 異常：紅（顯示「異常高 / 異常低」）
- 血壓圖的曲線依舊使用 **MAP（平均動脈壓）** 估計，並以 70–105 mmHg 作為教學級正常範圍。標籤方向則同時參考收縮/舒張壓與 MAP。

## 使用方式
- 頁首「📖 說明」會直接開啟此檔。  
- 左側人體圖上，腺體是一鍵脈衝：點擊立即分泌（衰減）。胰臟拆為**胰島素/升糖素**兩鍵。  
- 中央儀表的每張卡：
  - 右上角標籤會顯示**正常 / 偏高 / 偏低 / 異常高 / 異常低**。
  - 曲線上有兩條**水平虛線**對應該指標的**正常下界/上界**。
  - 當狀態偏離/異常時，**曲線顏色**一併變更以強化視覺提示。

## 提醒
- 數值和關係為簡化教學用，不代表臨床判讀門檻；課堂上可引導學生先觀察**方向**（高/低）再延伸討論。
