## 操作摘要（v0.25 起）
- 左側人體圖上每個腺體都是**SVG 按鈕**：點擊即觸發脈衝分泌（會隨時間衰減）。
- **胰臟拆兩鍵**：**胰島素**、**升糖素**。
- **性別切換**：男只顯示睪丸鍵；女顯示**雌激素/黃體素**兩鍵。

## 指標 → 建議激素按鈕（滑鼠懸停時套用）
> 方向判斷：相對正常範圍，**偏高/異常高=↑**、**偏低/異常低=↓**。只列主要、短期可行之「按一下就有效」的建議。

| 指標 | ↑（偏高/異常高）建議 | ↓（偏低/異常低）建議 |
|---|---|---|
| **體溫** | 女：**雌激素 Estro**（促血管舒張/出汗→散熱↑）。男：暫無直接激素建議（建議改環境降溫）。 | **甲狀腺素 T3/T4**（代謝產熱↑）、**E/NE**（散熱↓、代謝↑）。 |
| **血糖** | **胰島素**（降糖）。 | **升糖素**（升糖）。 |
| **血壓（MAP）** | 女：**雌激素 Estro**（舒張、壓下降）。男：暫無直接激素建議。 | **E/NE**（心輸出/阻力↑）、**醛固酮 Aldo**（血容量↑）。 |
| **心跳** | 無（避免再按 E/NE 以免更快）。 | **E/NE**（心率↑）。 |
| **代謝率** | 無（避免再按 T3/T4）。 | **甲狀腺素 T3/T4**、**GH**。 |
| **血鈣 Ca²⁺** | （本版無降鈣素按鈕，建議以腎/骨代謝教學延伸） | **PTH**（升鈣）。 |
| **血磷 PO₄³⁻** | **PTH**（腎排磷↑） | 無 |
| **細胞分裂** | **Cort**（抑制造成過高的分裂活性）。 | **GH**、**T3/T4**。 |

> 血壓圖使用 **MAP（平均動脈壓）** 曲線，教學級正常範圍設為 70–105 mmHg；方向判斷亦參考收縮/舒張壓。

## 腺體 → 主要作用（教學摘要）
- **GH（腦垂腺）**：組織合成/分裂↑、長期代謝調整。  
- **T3/T4（甲狀腺）**：基礎代謝↑、產熱↑。  
- **PTH（副甲狀線）**：血鈣↑、血磷↓。  
- **E/NE（腎上腺髓質）**：心率/血壓/血糖↑，抑制出汗與血管舒張。  
- **Cort（腎上腺皮質）**：升糖、應激代謝；高時抑制分裂。  
- **Aldo（腎上腺皮質）**：鈉水重吸收↑ → 血容量/血壓↑。  
- **Insulin（胰島）**：降血糖（攝取/合成↑）。  
- **Glucagon（胰島）**：升血糖（肝糖輸出↑）。  
- **Estro（卵巢）**：血管舒張、散熱↑、骨代謝保護。  
- **Proge（卵巢）**：體溫設定點上移。  
- （模型內含**降鈣素**生理效應，但本版未提供獨立按鈕）

## 體溫模型（v0.26 保留）
- 設定點 `= 37.0°C + 0.25×黃體素`。  
- 產熱 `= 基礎代謝 × 常數 + 顫抖/棕脂（低於設定點才啟動，受 T3/T4 與 E/NE 增益）`。  
- 散熱 `= 對流 ×（血管舒張可變）×（若高於設定點則加上出汗，雌↑/E/NE↓）`。
