# 人體恆定控制中心 — 內分泌回饋互動（v0.25）

> 本模型為教學近似，**非醫療用途**。本版將腺體改為「按鈕」，**按一下 = 觸發該激素的脈衝分泌**（隨時間衰減）。

---

## 使用重點
- 頁首「📖 說明」按鈕會在瀏覽器新分頁打開本檔（readme.md）。
- 左側人體圖上，每個腺體位置都是一顆**SVG 按鈕**；點擊後觸發對應激素的**脈衝**，並對「恆定指標」產生短/中效影響。
- 胰臟特別拆成兩顆按鈕：**胰島素**、**升糖素**。
- 性別切換：**男**僅顯示睪丸按鈕；**女**僅顯示卵巢兩顆按鈕（雌激素、黃體素）。
- 卵巢位置本版**上移 20 px**。

## 各「腺體按鈕」對應生理變化（規格草案）

> 下表列出「點一次按鈕」預設的影響方向／強度（↑/↓/±）、主要影響指標與典型半衰期（可於程式中微調）。

| 按鈕（位置） | 主要激素 | 影響主軸 | 影響指標（方向） | 典型半衰期（教學用） |
|---|---|---|---|---|
| **GH（腦下垂體）** | 生長激素 | 生長/同化、代謝 | 細胞分裂↑、代謝↑(輕)、血糖±（間接）、體溫± | ~90 分鐘 |
| **T3/T4（甲狀腺）** | 甲狀腺素 | 代謝/產熱 | 代謝率↑、體溫↑、心跳↑、血糖↑（利用率↑但交感敏感↑） | ~180 分鐘 |
| **PTH（副甲狀線）** | 副甲狀腺素 | 鈣/磷 | 血鈣↑、血磷↓ | ~80 分鐘 |
| **E/NE（腎上腺）** | 腎上腺素/去甲 | 交感應激（快） | 心跳↑、血壓↑（MAP、脈壓↑）、血糖↑ | ~20 分鐘 |
| **Cort（腎上腺皮質）** | 皮質醇 | 應激（慢）/產糖 | 代謝↑(糖異生)、血糖↑、血壓↑（緩） | ~120 分鐘 |
| **Aldo（腎上腺皮質）** | 醛固酮 | 水鈉保留 | 血壓↑（MAP↑，舒張↑） | ~100 分鐘 |
| **胰島素（胰臟）** | Insulin | 降糖/儲存 | 血糖↓、代謝組成偏向儲存 | ~50 分鐘 |
| **升糖素（胰臟）** | Glucagon | 製糖/肝醣分解 | 血糖↑ | ~50 分鐘 |
| **Testo（睪丸，男）** | 睪固酮 | 同化/血壓微升 | 代謝↑(輕)、血壓↑(輕)、細胞分裂↑(輕) | ~90 分鐘 |
| **Estro（卵巢，女）** | 雌激素 | 血管擴張/骨代謝 | 血壓↓(輕)、骨吸收↓→血鈣微↓、代謝↑(輕) | ~120 分鐘 |
| **Proge（卵巢，女）** | 黃體素 | 升溫 | 體溫↑（基礎體溫）、心跳± | ~120 分鐘 |

**說明**  
- 「↑/↓/±」為方向；實際幅度在程式內以脈衝參數轉換為目標激素值（`*Pulse` 參數），並以指數衰減表達半衰期。  
- 皮質醇與腎上腺素的時間尺度不同：E/NE 快、Cort 慢；醛固酮偏向影響血容量→MAP。  
- 甲狀腺素主導「代謝與產熱」，對心跳與血糖的影響多由交感敏感度改變而間接出現。  
- 雌激素具血管擴張與骨保護效應；黃體素使基礎體溫上移（約 +0.2–0.5°C）。

## 教學場景示例
- **餐後** 搭配按一次「胰島素」→血糖下降速度更明顯；  
- **冷暴露** 搭配按一次「T3/T4」→產熱↑，體溫較能拉回；  
- **運動中** 停止前按一次「E/NE」→短期心跳與血壓上升曲線更清楚；  
- **鈣補充** 與「PTH」對比→觀察 Ca/PO₄ 的相反趨勢；  
- **女/黃體期** 按「Proge」→體溫基線上移，並觀察心跳、血壓的小幅變化。
