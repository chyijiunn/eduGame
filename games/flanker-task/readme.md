# Flanker Task 小遊戲 v0.2

這個小遊戲是心理學裡常見的 **Flanker Task（干擾箭頭任務）** 的簡化版。  
畫面中間那一排箭頭，只有 **中間那一個** 才是目標，左右兩邊都是干擾。

---

## 遊戲規則

- 每一題會出現一排 5 個箭頭，例如：

  - `→ → → → →`  
  - `← ← → ← ←`

- **中間那個箭頭的方向** 才是正確答案。
- 左右兩側的箭頭可能：
  - 跟中間同方向（**一致題**）
  - 或和中間相反（**不一致題**）

你的任務：

- 只看「中間那一個箭頭」，
- 判斷它是：
  - 向左：按「選左邊」或鍵盤 `←`
  - 向右：按「選右邊」或鍵盤 `→`

---

## 操作方式

- 按下「開始遊戲」，一共會出 **10 題**。
- 每一題：
  - 會隨機決定是「一致」或「不一致」。
  - 會給你一小段時間作答（時間長度每題隨機，約 1.2～2.5 秒）。
- 你可以：
  - 點按畫面下方的按鈕：
    - `選左邊（←）`
    - `選右邊（→）`
  - 或直接使用鍵盤方向鍵：
    - `←` = 選左
    - `→` = 選右

---

## 分數與統計

遊戲結束後會顯示：

1. **得分**
   - 每答對一題加 1 分，滿分為 10 分。
2. **錯誤次數**
   - 選錯方向的題數。
3. **漏答次數**
   - 在限定時間內沒有按任何鍵，就算一次漏答。
4. **總作答時間**
   - 從按下「開始遊戲」到最後一題結束為止的總時間（秒）。
5. **平均反應時間**
   - 只計算有按出的題目：
     - 每題從「題目出現」到你按下答案為止的時間，取平均值（秒／題）。

## 心理學概念（給老師或進階玩家）

在真實研究裡，Flanker Task 主要用來觀察：

- **選擇性注意（selective attention）**  
  能不能只專注在中間目標，不被兩側干擾。
- **干擾抑制 / 衝突處理（interference control）**  
  左右箭頭方向如果跟中間不同，就會產生認知衝突。
- **處理速度與錯誤率**  
  一致題通常比較快、不一致題較慢且容易出錯。

在課堂或活動中，可以簡單地對學生說：

> 這是在考驗你：  
> 在很多干擾箭頭旁邊，能不能只專心看「中間那一個」的方向。

---

## 使用建議

- 可以讓學生輪流玩，觀察：
  - 自己的錯誤多數發生在「不一致題」嗎？
  - 自己是「快但容易錯」還是「慢但很少錯」？
- 可以讓同一個人多玩幾輪，看：
  - 平均反應時間是否隨著練習變快。
  - 漏答是否變少、錯誤是否減少。
