# 節奏音樂生成器 0.3

## 主要變更
- 根據 0.2 試聽問題調整混音與音色。
- 鼓組低頻加厚：kick 改成較低沉的合成低頻，取樣鼓只做輔助。
- 鋼琴改善：延音拉長、音量提高、加上空間感，減少乾硬感。
- 銅管提高音量與延音，讓高潮與落點更明顯。
- 吉他降低音量與密度，避免和鋼琴、銅管互搶。
- 節奏點間距稍微放寬，音樂不會一直像亂打點。
- 保留 0.2 的簡潔 UI：無 JSON 預覽、生成後自動播放、不顯示額外時間/節奏點/seed 欄位。

## 使用方式
直接開啟 rhythm_music_generator_v0_3.html。
放到 GitHub Pages 時也只需上傳 HTML。真實樂器 beta 需要網路載入外部 SoundFont 音源。

## 注意
音色仍是 SoundFont beta，不是真正錄音室樂手演奏。若要更接近商用品質，下一步應改成自備授權 sample pack 或接 DAW / MIDI 音源流程。
