# 節奏音樂生成器 0.1

單檔 HTML，開啟後可在瀏覽器端生成原創爵士節奏音樂。

## 功能
- 選擇樂曲長度：30 / 45 / 60 / 90 秒
- 選擇曲風情緒：乾淨 Swing、Noir、Playful、Intense
- 選擇節奏變化：由慢到急、穩定、越來越密集、多停頓重落
- 選擇難度：簡單 / 中等 / 困難
- Seed 可固定或隨機
- 可試聽
- 可下載 WAV
- 可下載節奏遊戲 JSON

## 使用方式
直接開啟 rhythm_music_generator_v0_1.html 即可。
放到 GitHub Pages 時，也只需要上傳這個 HTML 檔案。

## 限制
0.1 版使用 WebAudio 合成器音色，不是真實樂團錄音。
目前尚未加入 MIDI 與 MP3 輸出。
