
# 英文 Word Search 單字尋寶（教學版）

版本：0.4  
適用對象：國小三年級～國中九年級學生（支援自訂 CSV 字庫）

---

## 一、檔案結構與部署方式

建議同一資料夾內至少包含：

- `english_wordsearch_....html`：本遊戲主程式（單一 HTML 檔）。
- `readme.md`：本說明文件（可以自行修改）。
- （選用）`your_words.csv`：自訂單字字庫。

> **重要：**  
> 若你修改了本說明文件，請確保檔名仍為 `readme.md`，且和 HTML 檔放在同一層資料夾。  
> HTML 會透過 `fetch("readme.md")` 讀取並以 Markdown 方式渲染。

部署方式：

1. 直接在電腦上以瀏覽器開啟 HTML（有些瀏覽器對 `file://` 讀取 `readme.md` 可能有限制）。
2. 或放在學校網站 / GitHub Pages / 任意 HTTP 伺服器底下，建議放在同一資料夾中。

## 二、基本玩法介紹

1. 上方選擇 **字庫來源**：
   - 國小三～六年級、國中七～九年級（內建範例單字）。
   - 或載入自訂 CSV 字庫後選擇「自訂 CSV 字庫」。

2. 按下 **「產生新題目」**：
   - 系統會從該字庫抽出多個單字。
   - 自動產生一個 Word Search 盤面（約 10×10 ～ 18×18 的字母陣列）。
   - 同時在右側列出所有中文提示＋被隱藏的英文（以 `*` 顯示）。
   - 計時器自動從 `00:00` 開始計時。

3. 學生操作方式：
   - 用滑鼠（電腦）或手指（平板／手機）在盤面上 **點擊字母格**，即可加上／取消「標記」。  
   - 目標是把**每個英文字的所有字母位置**都標記出來。

4. 完成條件：
   - 系統會檢查每一個單字的每一個字母位置是否都有被：  
     - 自己標記（藍色標記），或  
     - 顯示答案後的綠色標記。  
   - 一旦 **所有單字都完成**：
     - 自動停止計時。
     - 跳出全畫面視窗，顯示「完成任務！」與最後用時。

## 三、計時與懲罰規則

### 1. 基本計時

- 每次按下 **「產生新題目」**：
  - 計時器歸零為 `00:00`。
  - 開始以秒為單位累加。

### 2. 使用提示（+5 秒）

- 按下 **「提示（+5秒）」** 時：
  - **立刻加 5 秒** 到目前時間。
  - 並依照「提示機制」解鎖英文單字的一部分。

提示邏輯如下：

1. **第一階段：首尾字母**
   - 優先讓每一個單字都至少露出 **第一個字母與最後一個字母**。
   - 每按一次，會為「某一個還沒補齊首尾的單字」補上首尾字母。

2. **第二階段：子音優先**
   - 當所有單字的首尾都已經揭露後，之後每次按提示：
   - 會在所有單字中，找出尚未顯示的 **子音**（非 A E I O U 的英文字母），逐個補上。

3. **第三階段：最後補母音**
   - 當再也沒有未揭露的子音時，提示開始顯示 **母音 A、E、I、O、U**。
   - 一次揭露一個尚未顯示的母音。

4. **全部揭露後**
   - 當所有字母都已經顯示出來，再按提示只會顯示訊息：
     - 「所有字母都已顯示，再按提示也只會加時間了喔！」
   - 同時 **仍然會加 5 秒**。

### 3. 顯示所有單字位置（+100 分鐘）

- 按下 **「顯示所有單字位置（+100分鐘）」** 時：
  - 系統會將盤面中所有單字的位置，以「答案顏色」標出。
  - 同時立即 **加 100 分鐘（6000 秒）** 到目前時間。
  - 狀態列會顯示訊息：  
    > 「加油，下次會更好！你選擇顯示所有單字位置，此次多加 100 分鐘作為練習懲罰。」

> 建議教學用法：  
> 把這個按鈕當作 **「放棄本局、看解答」** 的選項，讓學生知道：  
> 真的按下去就會有 **超大的時間懲罰**。

### 4. 隱藏答案與清除標記

- **「隱藏答案」**：  
  移除盤面上因「顯示所有單字位置」而產生的綠色答案標記，但不影響自己點的藍色標記。
- **「清除標記」**：  
  清除所有藍色標記（學生自行勾選的格子），時間不變。

## 四、右側單字列表與遮罩顯示

- 右側 `Word List & Clues` 區塊顯示：
  - 題號。
  - 中文解釋。
  - 字母數。
  - 英文單字（以 `*` 作為遮罩）。

- 透過提示系統，英文單字會：
  - 先露出首尾字母。
  - 再逐步露出子音。
  - 最後才露出母音。

- 當某個單字在盤面中被完整標示（每個字母位置皆被標記或顯示答案）時：
  - 對應的單字列會高亮，顯示為 **已完成**。

## 五、自訂 CSV 字庫格式

你可以準備一個簡單的 `.csv` 檔，讓老師自訂單字字庫。格式建議：

```csv
english,中文解釋
forest,森林
recycle,回收
volunteer,志工；志願者
```

規則：

1. 每一行代表一個單字。
2. 第 1 欄為英文：
   - 只會取 A–Z 字母，其餘符號會被忽略。
   - 少於 2 個字母的「單字」會被跳過。
3. 後面的欄位（第 2 欄起）會被合併當作中文解釋（逗號也會被保留）。
4. 不一定要有標題列。若有，也會依上述邏輯處理。

載入流程：

1. 點選上方的 **「📂 載入 CSV 字庫」**。
2. 選擇準備好的 `.csv` 檔案。
3. 若解析成功，年級選單會出現「自訂 CSV 字庫」選項並自動切換。
4. 按下 **「產生新題目」** 就會以自訂單字建立盤面。

## 六、教學情境建議

- 國小中年級：
  - 可以只用較短的單字（3～6 個字母），搭配顏色、動物、教室物品等主題。
- 國小高年級：
  - 搭配自然、社會或英文課單字，訓練 **拼字與字形辨識**。
  - 可鼓勵學生自行製作 CSV 字庫。

- 國中：
  - 可搭配課本單字、主題字庫（例如：環保、科技、情緒字彙等）。
  - 利用「提示懲罰」與「顯示答案懲罰」設計比賽：  
    - 使用提示次數少、總時間最短者獲勝。
