# genGrift 專案詳盡文字對談紀錄

本文件為 genGrift 從 0.43 架構演化至 0.5
完整雙引擎版本的詳細對談紀錄整理。
內容依實際討論邏輯順序重建，包含設計決策、版本轉折點與技術原理。

------------------------------------------------------------------------

# 一、專案起點

使用者提出希望重建早期達爾文演化 SWF 遊戲： - 玩家提供突變 -
環境隨機篩選族群 - 不適合者淘汰

但進一步要求： - 不只是突變數值遊戲 - 要加入基因概念 -
要能看到等位基因比例 - 必須包含交配 - 可用於教學

------------------------------------------------------------------------

# 二、核心設計決策

1.  偏科學正確（族群遺傳導向）
2.  必須有交配與下一代
3.  顯示等位基因比例 p 曲線
4.  允許玩家手動改初始 allele 頻率
5.  玩家只能微調（Δp ≤ 0.05）

------------------------------------------------------------------------

# 三、從 0.43 到 genGrift 的轉型

0.43 僅為個體層突變與環境篩選。 決議新增族群層變數：

pState = { F, C, S, R }

並加入： - 自然漂移 - 玩家微調 - 成本連動 - 環境推薦方向

------------------------------------------------------------------------

# 四、版本演進摘要

## genGrift 0.1

-   加入 pState
-   基因 Modal
-   成本機制
-   僅 F 漂移 → 體感與 0.43 差異不大

## genGrift 0.2

-   基因卡 50%
-   p 影響下一代性狀
-   使用平衡權重 → 族群開始被塑形

## genGrift 0.3

-   四基因漂移
-   基因圖表 → 可視化演化

## genGrift 0.4

-   四種基因卡
-   事件推薦方向 mapping
-   疾病事件
-   修正 sceneBias bug

## genGrift 0.4.2

-   基因曲線四色區分

## genGrift 0.5

-   初始 allele 可手動調整
-   初代族群依 pState 生成
-   完整雙引擎結構

------------------------------------------------------------------------

# 五、核心理念

-   環境是真實選汰壓力
-   基因頻率屬族群層級
-   演化為累積過程
-   教學可視化優先
