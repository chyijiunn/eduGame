# 折射與三稜鏡色散（微觀電子視角）— 使用說明

> 檔名建議：`refraction_prism_micro.html`（本專案為單一 HTML，可離線使用）

---

## 1. 教學目標（給教師）
- 以**微觀電子的「被光帶著晃」**視角，連結到**宏觀折射與色散**。
- 認識折射率 \(n\) 與波長 \(\lambda\) 的關係：一般可見光中 **藍光的 \(n\) 較大、紅光較小**（正常色散）。
- 觀察三稜鏡如何把白光分解成彩帶，並用**最小偏向角近似**建立量感：\(\delta\approx(n-1)A\)。

## 3. 介面導覽

### 3.1 左側控制區
- **介質選擇**
  - 外側介質（稜鏡外）：真空 / 空氣 / 水
  - 稜鏡材質（內部）：水 / 玻璃（BK7） / 透明壓克力（PMMA） / 空氣 / 真空
  - 下方表格即時顯示三色（紅 656nm、綠 546nm、藍 486nm）在外側、內部的折射率 \(n\) 近似值。
- **光束與觀察**
  - 入射角（°）：調整入射光方向。
  - 光型態：白光（RGB 展開）或單色（可滑桿 400–700 nm）。
  - 顯示選項：
    - 「法線」：在介面標示面法線輔助理解入射／折射角。
    - 「全反射提示」：臨界角後以虛線給予 TIR 提示。
    - 「網格」：開啟背景網格。
    - 「最小偏向近似」：顯示 \(\delta\approx(n-1)A\) 的估算（以綠光代表）。
    - 「電子視角」：開／關微觀動畫。
- **工具列（上方）**
  - 下載 HTML：一鍵存檔（打包為單檔）。
  - 重置：回到預設（外：空氣、內：BK7、白光、入射角 10°）。

### 3.2 右側兩張畫布
- **宏觀：三稜鏡色散（幾何光學）**
  - 等邊稜鏡（頂角 \(A=60^\circ\)）。
  - 白光時會以 R/G/B 三束顯示不同偏轉；單色時以該色繪製。
- **微觀：電子被光驅動的「慢半拍」**
  - 把材料裡的**束縛電子**想成「彈簧球」。
  - 當光（電場）通過時，電子跟著被驅動但**慢半拍**（相位落後）。
  - **相位延遲**越大 → 材料中的**相速度**越慢 → **折射率 \(n\) 越大**。
  - 以**波長不同 → 頻率不同**的想法解釋：藍光頻率更高，彈簧球更難跟上 → 相位延遲更大 → 較大的 \(n\)。

## 4. 背後原理（摘要）
- **斯涅爾定律**：\(n_1\sin\theta_1=n_2\sin\theta_2\)。
- **最小偏向角近似**（教學量感）：\(\delta\approx(n-1)A\)（弧度）。
- **色散**：\(n(\lambda)\) 隨波長而變；在可見光的正常色散範圍 \(\tfrac{dn}{d\lambda}<0\)。
- **微觀機制**：入射光的電場驅動束縛電子 → 再輻射二次波，與入射波干涉 → 形成**相位延遲**與有效相速度降低（視為 \(n>1\)）。

> 內建數值為**教學近似值**（三色端點插值），重在展示趨勢：\(n_\text{藍} > n_\text{紅}\)。若需高精度，請改用實測或玻璃供應商資料（如 Sellmeier 係數）。

## 5. 課堂活動建議
1. **藍彎多、紅彎少**：外：空氣、內：BK7，白光入射。觀察 RGB 出射角差異，口頭歸納規則。
2. **換材質比較**：把稜鏡材質切換成水與 PMMA，比較色散強弱（張開角度）。
3. **外介質效應**：外側改「水」，內部固定 BK7，觀察臨界角與全反射提示如何變化。
4. **單色掃波長**：切單色模式，從 700nm → 400nm 緩慢掃描，記錄折射角如何隨 \(\lambda\) 變化。
5. **快速估算**：勾選「最小偏向近似」，用 \(\delta\approx(n-1)A\) 比對畫面，建立「量級感」（非嚴格等於）。
6. **連結鏡頭色差**：討論材料色散（阿貝數）與攝影鏡頭為何要用低色散玻璃／複合鏡片做**消色差**。

## 6. 常見問題（FAQ）
- **畫面空白或失真？** 刷新頁面；或在瀏覽器關閉「降低動作效果」類的輔助設定再試。
- **手機上拖動不靈敏？** 本頁主要為按鈕與滑桿操作，建議裝置橫向持握，避免誤觸回上一頁手勢。
- **看不到彩帶？**
  - 確認「光型態」為「白光」。
  - 入射角若太小或材質色散弱，RGB 分離角度會較小，可增大入射角或改用 BK7／PMMA 比較。
- **全反射線出現是什麼？** 代表該介面在目前幾何下達到臨界角而無法折射，只能反射（TIR 提示線）。

## 7. 客製化（教師／進階）
> 打開 `refraction_prism_micro.html` 原始碼並搜尋 `const media = { ... }`。

- **新增材質**
  ```js
  pmma: { zh:'透明壓克力（PMMA）', n:(nm)=> interp(nm, {r:1.488,g:1.492,b:1.496}) }
  ```
  複製一行、改成你的材質代號與中文名，把 `r/g/b` 三色的折射率端點填入。
- **改用更精細模型**
  - 若有 Sellmeier 係數，可把 `n:(nm)=> ...` 改寫成 `n_Sellmeier(λ)` 形式。
  - 也可用 Cauchy 公式近似：\(n(\lambda)=A+\tfrac{B}{\lambda^2}+\tfrac{C}{\lambda^4}\)。
- **調整稜鏡角**
  - 目前預設等邊（\(A=60^\circ\)）。搜尋 `const prism = { A: Math.PI/3 }`，修改 `A` 即可。
- **預設入射角、預設模式**
  - 搜尋初始化區塊（`#btnReset` 旁邊），變更 `ang.value`、`selMode.value` 等。

## 8. 評量建議（形成性）
- 能以**微觀語言**描述為何藍光折射率比紅光大（提到「跟不上 → 相位延遲更大」）。
- 能以**宏觀語言**描述稜鏡色散，並指出「藍彎多、紅彎少」。
- 能用 \(\delta\approx(n-1)A\) 做**估算**並解釋其限制（只作量級、非嚴格等於）。
- 能解釋**外介質**改變（如空氣→水）時臨界角與折射路徑的差異。
