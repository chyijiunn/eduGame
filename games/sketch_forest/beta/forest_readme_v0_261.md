# 漫苗森林 sketch forest v0.261 說明

v0.261 是 v0.26 的穩定修正版，目標是修正「主畫面沒有樹、沒有動物、小地圖與折線圖沒有資料」的問題。

## 操作

- 電腦：
  - W：往視野前方前進
  - S：後退
  - A / D：左右側移
  - 滑鼠移動：轉動視角
  - Tab：切換滑鼠鎖定 / 解鎖
  - 滑鼠滾輪：縮放視角
  - 滑鼠左鍵：消滅準星上的生物、移除樹，或在空地放置果實

- 手機 / 平板：
  - 單指拖曳：旋轉視角
  - 雙指捏合：縮放
  - 左下搖桿：移動
  - 右下按鈕：消滅 / 種果實

## v0.261 修正重點

1. 重新檢查初始化流程，避免 JS 中途錯誤導致 3D 場景完全不出現。
2. 初始化後一定會建立地面格線、多棵線稿樹、河流、五種動物、果實、迷你地圖與生物量圖。
3. 修正松鼠、鳥、蝴蝶靠近果實卻吃不到：進食改用水平距離與高度容許，不再只用完整 3D 距離。
4. 蝴蝶躲藏限制：遇到鳥會躲進樹叢；若樹上沒有果實，最多躲 1 小時，之後必須離開。
5. 動物改成目標導向移動：餓了找食物；吃飽找同種異性；沒有目標時探索森林其他區域。
6. 自然繁殖後會立刻更新統計數字。
7. 說明視窗會以 Markdown 標題、清單、表格等形式呈現。

## 生物規則簡表

| 物種 | 食物 | 特色 |
|---|---|---|
| 蝴蝶 | 樹上果實 | 會飛，遇到鳥會躲樹，但不能無限躲 |
| 鳥 | 蝴蝶、樹上果實 | 優先捕食蝴蝶，視野大 |
| 松鼠 | 樹上果實、地面果實 | 可在樹上與地面移動 |
| 兔子 | 地面果實 | 地面速度快，吃飽後容易繁殖 |
| 麋鹿 | 樹葉 | 吃樹會降低樹的生物量 |

## 生物量

- 總生物量：所有動物體重加總。
- 樹生物量：所有樹的 energy 加總。
- 詳細圖可勾選蝴蝶、鳥、麋鹿、兔子、松鼠、果實、樹生物量。

## 生殖

- 同種、異性、兩者都吃飽、距離夠近，才會繁殖。
- 生殖後產生一隻新個體，父母體重減半，父母重新進入飢餓狀態，生殖潛能減 1。
- 生殖潛能用完即死亡。
- 生殖瞬間會顯示愛心與右上角出生訊息。
