# 漫苗森林 sketch forest v0.181

本頁面模擬一個線稿 3D 森林生態系，包含蝴蝶、松鼠、兔子、麋鹿、鳥等動物，
並用「體重」代表生命值與能量，搭配每日代謝、覓食、生殖條件與死亡門檻。

v0.18 之後的重點修正：

- 點左側統計面板新增任一動物時：
  - **新生個體會出現在「第一人稱視角中央十字準星所對準的地面位置附近」**，
    而不是地圖中心或隨機位置。
  - 若十字準星沒有交到地面（例如你抬頭看天空），則該次新增動物不會產生。
- 其他與 v0.18 相同：
  - 十字準星點擊：
    1. 對準「動物」→ 消滅該動物；
    2. 對準「樹木」→ 砍掉該棵樹；
    3. 若都沒命中 → 在準星對準的地面位置種 1 顆果實。
  - 生物會因為飢餓（體重低於原始體重 30%）、被捕食、或被玩家消滅而消失，
---

## 操作摘要

### 電腦

- 滑鼠移動：旋轉視角（在 Tab 切到「視角模式」時）。
- Tab：切換滑鼠模式：
  - 視角模式：游標隱藏，以中央十字為準心，滑鼠移動會旋轉視角。
  - 編輯模式：游標顯示，視角固定，可操作介面與按鈕。
- W / S：前進、後退（沿視線方向）。
- A / D：左右平移。
- 滾輪：視角縮放。
- 滑鼠左鍵（中央十字）：
  1. 若對準動物 → 消滅該動物。
  2. 若對準樹木 → 砍掉該棵樹。
  3. 若都沒命中 → 在十字準星對準的地面位置種 1 顆果實。
- 左側統計面板：
  - 點「果實」：一次增加 10 顆果實（隨機掛在樹上）。
  - 點「蝴蝶／松鼠／兔子／麋鹿／鳥」：
    - 新增個體會出現在「十字準星所瞄準的地面附近」。
    - 若準星無法投射到地面（看天空）則不會生成。

### 手機 / 平板

- 左下搖桿：模擬 WASD 方向移動。
- 單指拖曳：旋轉視角。
- 雙指：縮放視角。
- 右下十字按鈕：
  - 功能與滑鼠左鍵相同（消滅動物／砍樹／在準星地面位置種果實）。
