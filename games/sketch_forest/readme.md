# 漫苗森林 sketch forest v0.16

本頁面模擬一個線稿 3D 森林生態系，包含蝴蝶、松鼠、兔子、麋鹿、鳥等動物，
並用「體重」代表生命值與能量，搭配每日代謝、覓食、生殖條件與死亡門檻。

## 操作方式
- 電腦：
  - 滑鼠移動：旋轉視角（中央十字為準心）。
  - W / S：前進、後退（沿視線方向）。
  - A / D：左右平移。
  - 滑鼠左鍵：如果準心對到某生物，將其消滅。
  - 滾輪：視角縮放。
- 手機 / 平板：
  - 左下搖桿：模擬 WASD 方向移動。
  - 單指拖曳：旋轉視角。
  - 雙指：縮放視角。
  - 右下十字按鈕：消滅準心上的生物。

## 生態邏輯（簡要）
- 果實：
  - 會從樹上長出並掉落地面。
  - 如果沒被吃掉，落地後會長出小樹，小樹會在迷你地圖上用較亮綠色顯示。
- 動物：
  - 從 v0.16 起，「甲蟲」改為「蝴蝶」。
  - 五種動物依能量塔概念有不同體重與每日需求：
    - 蝴蝶：初始體重 2，每日需求食物值 3，每日不足時扣重 0.1。
    - 松鼠：初始體重 40，每日需求 10，每日不足扣重 1。
    - 兔子：初始體重 40，每日需求 10，每日不足扣重 1。
    - 麋鹿：初始體重 200，每日需求 30，每日不足扣重 5。
    - 鳥：初始體重 100，每日需求 15，每日不足扣重 2.5。
  - 體重低於初始值的 30% 視為死亡並從場景移除。
- 食物與體重：
  - 果實重量 = 1；每吃到一單位食物，體重 += 0.1 × 食物重量。
  - 鳥吃蝴蝶時，以蝴蝶體重當作食物重量。
  - 若已吃到「當日需求食物量」，之後不再增加體重，只是保持狀態。
- 生殖條件：
  - 每隻動物有性別（出生隨機決定）。
  - 當「累積攝食量」達到「自身初始體重 0.5 倍」且與同種異性接近時，有機會產生新個體。
  - 各物種生殖潛能（最多可生幾次）：
    - 蝴蝶：100 次
    - 松鼠：10 次
    - 兔子：10 次
    - 麋鹿：2 次
    - 鳥：5 次
  - 生殖後親代體重會下降一小部分，生殖能量被清空大半，生殖潛能 -1。
