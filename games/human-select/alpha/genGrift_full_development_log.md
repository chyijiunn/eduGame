# genGrift 完整開發紀錄（Detailed Development Log）

------------------------------------------------------------------------

# 一、專案起源

## 1.1 初始問題

使用者希望重建一款早期 SWF「達爾文演化遊戲」：

-   玩家提供突變
-   環境隨機篩選
-   不適合者淘汰
-   族群存活與否取決於特徵

但希望升級為：

> 不只是性狀加減，而是真正的「族群遺傳系統」。

------------------------------------------------------------------------

# 二、設計核心原則

1.  科學正確（接近族群遺傳學）
2.  必須包含交配
3.  必須有等位基因頻率（p）
4.  環境不是皮膚效果
5.  玩家只能微調（不可暴力洗數值）
6.  可教學用途（國高中層級）

------------------------------------------------------------------------

# 三、架構轉型（從 0.43 到 genGrift）

## 3.1 0.43 架構（原始版）

-   個體層演化
-   突變卡直接影響 trait
-   環境篩選影響存活
-   無族群基因概念

缺點： - 無法呈現 Hardy--Weinberg 思維 - 無基因庫動態

------------------------------------------------------------------------

# 五、系統分層結構

## 族群層

-   pState（F/C/S/R）

## 個體層

-   fur
-   camo
-   speed
-   size（暫代 R）

## 遺傳層

-   交配生成
-   traitMu(p) 拉動

## 漂移層

-   survivor phenotype → pHat → lerp

## 事件層

-   score(ind) → survival probability

## UI 層

-   Modal
-   折線圖
-   基因卡

------------------------------------------------------------------------

# 六、設計哲學

1.  族群比個體重要
2.  演化是累積過程
3.  環境改變會推動基因頻率
4.  玩家不能無限洗數值
5.  教學可視化是核心價值
