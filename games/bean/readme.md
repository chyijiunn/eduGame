# 豆子摩擦力實驗操作說明

這個互動頁面有兩個場景，目標是觀察「顆粒堆積」與「顆粒卡塞」如何受到摩擦力與密度影響。

## 場景一：豆子倒在桌面上

畫面中央有三個區域，可以分別倒入豆子做比較。

操作方式：

1. 上方的「豆」滑桿可以設定一次倒入的豆子數量，範圍是 100 到 500。
2. 按下「倒」後，豆子會落到桌面並形成堆積。
3. 下方三個滑桿可以改變同一區域的條件：
   - ρ：豆子密度。密度越大，下層受到的壓力越明顯，堆積會更容易壓實。
   - μ豆：豆子和豆子之間的摩擦。數值越大，豆子越不容易彼此滑開。
   - μ桌：桌面和豆子之間的摩擦。數值越大，底層豆子越不容易向外滑動。
4. 豆子停止移動後，畫面下方會顯示該豆堆的高度與面積。
5. 按下重置符號，該區會清空豆子，並把數值恢復預設。

觀察重點：

- μ豆較大時，豆堆通常比較陡，也比較能往上堆高。
- μ桌較大時，底部比較不容易散開，豆堆的擴散面積可能變小。
- ρ較大時，可以想成下層承受較大的壓力，顆粒之間更容易被壓緊。

## 場景二：木棒插入豆子杯

這個場景呈現一根或多根木棒插入豆子中，當摩擦條件足夠時，木棒往上拉會把整杯豆子一起提起；條件不足時，木棒會滑出來。

操作方式：

1. 每個杯子上方有豆量滑桿與「放」按鈕。
2. 每按一次「放」，杯內會增加 100 顆豆子，最多 500 顆。
3. 也可以直接拖曳豆量滑桿，設定杯內豆量。
4. 每個杯子下方有兩個參數：
   - μ棒：棒子材質等級，代表豆子與棒子之間的摩擦力，等級 1 到 3。
   - ρ：豆子密度等級，等級 1 到 3。
5. 右側的「＋」可以增加棒子，最多 5 根；「－」會先移除最後新增的棒子。
6. 用滑鼠或手指拖曳棒子插入杯中。
7. 插入後往上拉：
   - 條件足夠時，杯子會跟著棒子一起被提起。
   - 條件不足時，棒子會從豆子中滑出。
8. 開啟「力圖」後，可以看到豆子對棒子的摩擦力箭頭。

觀察重點：

- 插得越深，棒子和豆子的接觸面越多，總摩擦力越大。
- 豆子越多，能接觸棒子的顆粒越多，總摩擦力越大。
- 豆子密度越高，可以想成側向壓力越大，棒子受到的摩擦效果越強。
- 棒子材質等級越高，代表棒子表面越容易被豆子「咬住」。
- 多根棒子同時插入時，摩擦力可以一起作用，比單根棒子更容易形成卡塞效果。

## 這不是完整真實物理

這個頁面使用簡化模型，重點是幫助觀察趨勢。真實豆子還會受到形狀、大小、表面粗糙度、杯壁摩擦、棒子粗細、插入角度等因素影響。這裡先把那些因素固定，方便比較密度與摩擦力的效果。
