## Hanenbow 使用說明
模擬《電子浮游生物》中的 Hanenbow (ハネンボウ)，長得像蝌蚪那樣種會彈跳的生物，撞擊弦線枝條時會產生音符，點一下花苞發射器可發射一隻，拖曳發射器本體可移動位置、拖曳瞄準點可改角度與拋射距離。拖曳弦線中央可移動位置、拖兩端改角度與長度、點一下線中央可換和弦。
下方兩滑桿分別控制：發射間隔與粒子大小。發射間隔拉到最右側代表不連發；粒子越大越重、落得更快也拋得更近，粒子越小則會飛得更遠。右下角 <strong>＋／－</strong> 可新增/刪除和弦線右上角更多按鈕可調整音色、重置、線段調性、是否啟用，以及主畫面是否顯示和弦名稱。
## 版本
- 0.23 UI 改進
- 0.22 花苞發射時張開再閉合動畫、枝條末端的小花更明顯的層級差，讓高連擊時更有「盛開」感。新增小生物落到畫面最下方時，在最下方產生水波紋，搭配一個水滴落的和弦。
- 0.2 小蝌蚪與撞擊小動畫，介面物件豐富一點，發射器像花苞一點。葉脈花梗型現在還是硬板板的直線，保留中間碰撞的線，外型上稍微有點曲線，有點像自然的莖條
- 0.19 UI仿手機面板設計，提高玻璃音色的音量、刪除竹音、木琴、人聲、鐵琴，並新增和鳴與鼓組。和鳴：為泛泛之音，有嗡嗡聲，為類似助眠音的 alpha wave ，不像白噪音那樣的吵雜、鼓組：鼓組當中不一定要照音階，可以在現有模式中加入鑼、鈸等不同打擊樂要素進入鼓組，鼓組擺在最下面。
- 0.18 UI 改進
- 0.16 一開始的調先三個，為 C , E , A，後面按增加的時候補進來 B , D , F , G ,接下來則是有升記號的，每次新增的和弦都隨機不同。一開始的發射器位置也隨機，每次重置也都會不相同。目前執行有遇到一個問題就是發射太過密集十，可能是瀏覽器運算延遲的關係，導致聲音很拖延且手機會發燙。
- 0.15 部分球會穿過線，每顆球每幀依照位移距離，自動拆成多個小步，每小步都做一次碰撞檢查與反彈，因此斜線、細線、小球、高速時，比原本更不容易穿過
- 0.14 畫面首次進入時，和弦都集中在左上角，請改成位置、角度、長度皆隨機分配，而每次重置按下時，也符合隨機分配的規則。發射間隔預設無限大，讓使用者一開始點選發射器，顆粒大小會影響發射的因素，越大顆拋得就越近、越小顆拋得越遠，大小顆為影響物理重力引擎的因素。右下角的減號每按一個就減少一個，減少的順序為越是新近新增就越早刪除，若為一開始都是同時出現的，就高音調的先消失。新增和弦規則，若短時間內重複敲到和弦，和弦顏色會發生轉變，會變得越來越鮮艷，但若沒有敲擊到，就會冷卻回來自然色。
- 0.13 <head> 後加入 GA :<script src="/eduGame/ga4.js"></script>。若視窗有拖拉或因為手機平板轉橫式又打回直式時，把視窗外的和弦棒自動移回來視窗內。將發射間隔和顆粒大小移出更多，改放在主畫面下方，取消連發開關，當發射間隔無窮大時代表沒有連發。這兩個滑桿式的控制用圖示來表達，不要寫出來，維持畫面簡潔，並寫入一開始的說明即可。和弦線設定因為點和弦就可以改調性，所以僅保留調，把和弦選項在選單中去除，且不列出線段名稱，再將和弦欄位儘量縮併，不要讓畫面往下滑太多。清空粒子、清除場景、清空暫存、統一為一個按鈕叫做重置，擺在最上面就好。在更多選單內可選擇開啟或關閉主畫面線段和弦名稱，讓畫面簡潔，並再將不同和弦刷不同漸層顏色仍以自然色系為主。
- 0.12 根據使用者是否有瀏覽器暫存，若無，第一次點入時呈現浮動視窗，說明介面操作方式，點選關閉後以後不會再出現，並記錄暫存，記錄使用者設定，除非進入更多按鈕後點選清除資料，否則維持上次進入頁面設定。點選任何設定後就隨即套用，不需要點選確認。檔名僅保留 v0.12即可。取消速度設定，直接改於發射器前的瞄準虛線可拖曳，拉越長發射速度越快。新增畫面右下角一個 + 和一個 - 按鈕，按下+後可以增加和弦的線，按下-後可點選和弦刪除，更多和弦的設定放入更多設定裡，可控制和弦的調，和弦可控制開關，將和弦名稱標記小小白色字的放在線中央，一開始的和弦先五個就好，所有相關的設定值寫入程式內的註解，方便使用者去更動參數
- 0.11 發射器位置可自由移動，旋轉角度可拖曳修改、點按發射器就是發射一個， 重力、連發間隔、粒子大小、音色 放在更多的點點點按鈕才出現浮動視窗來調整，原始畫面不放說明文字，包含和弦名稱也不呈現，
