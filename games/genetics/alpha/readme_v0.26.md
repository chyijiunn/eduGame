## 基本操作

- 點選染色體上的字母：切換等位基因（固定：**大寫＝顯性，小寫＝隱性**）
- 電腦：左鍵拖曳平移、滾輪縮放
- 手機/平板：單指拖曳平移、雙指縮放/平移
- 右上角「重置視角」：自動縮放置中，確保元素盡量都在畫面內

## 關卡介紹

### 1-1 基本概念（單性狀：顯隱性）
- 基因座：`A/a`
- 點兩條染色體改基因型，按「檢查」
- 規則：`AA` 或 `Aa` → 顯性外觀；`aa` → 隱性外觀
- 答對會顯示大字「答對」

### 1-2 單性狀：雜合出子代
- 左：母親；右：父親
- 按「雜合」：母、父各抽一條（配子）組成子代
- 中間顯示子代外觀與基因型

### 1-3 單性狀：反推父親
- 母親已知；父親未知（顯示「？」避免提示）
- 每按一次「雜合 +20」生成 20 隻寶寶（已縮小與縮距，避免擋住染色體）
- 觀察 `AA / Aa / aa` 分布推測父親基因型，可回溯/揭曉

### 2-1 兩性狀：連鎖配對
- 同一條染色體同時帶 `E/e` 與 `T/t`
- 外觀：
  - 耳朵：`E` 顯性→垂耳；`ee`→尖耳
  - 尾巴：`T` 顯性→捲尾；`tt`→直尾
- 點染色體字母改外觀，按「檢查」

### 2-2 兩性狀：雜合出子代
- 按「雜合」：母父各抽一條連鎖染色體，組成子代
- 顯示子代外觀與基因型（`EE/Ee/ee`；`TT/Tt/tt`）

### 2-3 兩性狀：反推父親
- 父親未知（顯示「？」）
- 每次「雜合 +20」生成 20 隻寶寶，觀察外觀比例推測父親基因型
- 可回溯/揭曉，猜中顯示「答對」
