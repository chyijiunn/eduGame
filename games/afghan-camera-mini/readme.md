	2. 過錳酸鉀 + 稀硫酸，使用 75 + 75 ml
	3. 離箱、過水，去過錳酸鉀的粉紅色後，呈現淡黃色
	4. 再曝光
	5. D72
	6. 過水
	7. 海波

# 製作
1. [設計透鏡](https://chyijiunn.github.io/eduGame/games/len-design/)或購買透鏡，針對焦距設計結構，根據透鏡焦距設計一到兩倍可成像距離的箱體
2. 板材 15 mm 厚度 13.5 公分 長度 1 公尺
3. 板材橫切四等份，內部建議上平光黑漆並做防水，或者使用火烤
4. 對焦屏製作
	1. 雷射切割白霧壓克力板大小是 3.5×5 吋相紙一半，上白膠後貼合入對焦板，對焦板後方有畫圓，壓克力霧面朝前、亮面朝後
	2. 霧面壓克力邊緣黏貼合後，周圍黏一個 L 型黑紙，另一個對位、但不要黏。再黏透明壓克力方框，卡榫輔助相紙在黑暗當中卡入正確位置，對位用的  L 型黑紙 於透明方框乾燥之後取出。
	3. 取 20cm 圓棒於對焦板中央圓形處、螺絲鎖上，為對焦桿，方便拉伸之用
5. 加工各板件，依使用者方向稱為前板(光圈位置)、上板、下板、後板、右板(面對前方的右邊)、左板 
	1. 前板組裝虹膜光圈機構，有三層，以竹籤貫穿，中間層為鬆配、前後為緊配，並在最外側黏上兩圈圓環作鏡頭蓋卡合處
	2. 右板
		1. 正中央開一個圓洞以線鋸機鋸切直徑為 10 公分
		2. 剪下褲管從腳踝到膝蓋，長度約成人手肘到手腕。用釘槍環形釘上褲管
	3. 後板間中央為 4cm 圓洞，用來觀測是否對焦用，外側需做遮光
	4. 上板和左板
		1. 開一個觀察孔圓孔 1 5/8"(41.25cmm)，觀察是否顯影完畢用。
		2. 孔徑內測環形貼遮光海綿
		3. 圓形紅色壓克力放入，若會鬆脫，則黏合
		4. 加遮光蓋
	5. 下板可選配開腳架鎖孔，以 1/4 螺絲攻牙，箱體完成後再回來鑽也可
6. 組裝箱體
	1. 黏合上板、左板、下板、前和後板。
	2. 在前板和後板乾之前貫入兩圓棒，圓棒和板之間先不黏合
	3. 對焦板以 26 cm 兩圓棒穿過圓孔，平行地固定在箱體內上側，使對焦屏幕可在內部平行滑動且不卡住
	4. 多的小圓片黏貼前後板連結圓棒，避免滑動
	5. 最後組裝右板，鎖上鉸鏈，右板關閉的內部，接觸邊角都貼遮光海綿
	6. 檢查是否漏光處，補遮光海綿
# 使用步驟
- 拍攝前
	1. 確認
		1. 藥水槽前往後為顯影劑和定影劑
		2. 所有孔洞關閉狀態
		3. 右板門片緊閉
	2. 轉移數張相紙入暗箱內相紙庫存區
	3. 前板光圈放到最大，透過後板對焦窗孔觀察、拉伸對焦桿移動對焦屏幕，確認拍攝物是否邊緣清楚呈現、邊界是否於拍攝範圍內
	4. 固定對焦桿位置
	5. 關上對焦窗孔、鏡頭蓋，避免漏光
	6. 將對焦桿拉到最後
	7. 不留指紋(最好是戴上手套)進行這項作業：
		1. 手進入箱體
		2. 將相紙從庫存區取出
		3. 弧面凸起面是感光面，稍微地將它反折回來、盡可能反攤平
		4. 放入對焦屏上卡榫位
	8. 對焦桿推回固定對焦位置
- 拍攝時，評估測光，[決定曝光時間](https://chyijiunn.github.io/eduGame/games/light-meter/exposure.html)需要多久
	1. 室外強光建議縮小光圈、拉長時間
	2. 室內環境建議放大光圈、打閃燈，需多久得經驗累積，可能至少要兩秒
- 拍攝後，鏡頭蓋上，避免再度漏光
	1. 相紙取出，放入顯影盆，顯影時間建議在 30 - 60  秒左右，根據藥劑、水溫、相紙感光度來決定，使用前應經過實際測試。可透過紅窗確認是否顯影，紅窗視需要外加手電筒往顯影槽打光，若在戶外，上方加蓋黑布可以避免壓克力反光較易觀察。
	2. 相紙夾出，顯影盆上方滴落藥劑，入定影液槽，定影時間約為兩倍顯影時間內
	3. 定影完成開箱取出，建議連續沖水將錯合物沖掉，時間至少10分鐘，無法水沖時改以泡水、換水的方式處理
# 藥劑
傳統阿富汗相機僅需兩種藥劑，若相紙面積為 8.9 x 6.35 cm，需要液面高度為 1.5 cm，則需要體積為 100 ml，為方便計算以及配置，以下泡兩份，共 200 g 來計量 
1. 顯影劑：咖啡顯影配方，1L / 5 = 200ml 藥劑
	- coffee 40g / 5 = 8 g 
	- KBr 1g /5 = 0.2 g 
	- 碳酸鈉 54 g  / 5 = 10.8 g 
	- 維生素Ｃ 16 g  / 5 = 3.2 g 
2. 定影劑：重量百分濃度 20% 硫代硫酸鈉
	- 40g 硫代硫酸鈉
	- 160 ml 水
3. 若需漂白藥劑進行反轉，為環保需求用鐵系漂白配方，金屬離子對環境生物危害較低
	1. 氯化鐵 (III) 六水合物（FeCl₃·6H₂O）：20 g
	2. EDTA 二鈉鹽（Na₂EDTA）：20 g
	3. 檸檬酸：10 g
	4. 水：補至 1000 mL
