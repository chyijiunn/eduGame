# Dune Lab v0.55 — CFD 地形貼合與氣流粒子密度

由 v0.54 延續，單一 `index.html` 可部署 GitHub Pages，保留原有所有地形演化、粒徑組成、歷史風場、時間倍率、畫質及相機旋轉操作。

## 更新
- CFD 氣流示蹤線每幀依「目前」的沙丘高度調整下邊界；沙丘升高或降低時不再沿用舊高度投影線段，也避免流線穿入最新地表。
- 對 CFD 三維速度場使用三線性插值，在地形小幅變化時調整取樣高度；地形相對求解網格變化超過約 0.38 m 時，將新的地形邊界送進既有 Worker，更新流固遮罩並在新暴露的空氣格點初始化流速，避免頻繁全部重啟 CFD。更新期間停止把過期風場送回輸沙模型，時間仍繼續推進。
- CFD 開關開啟後才顯示「CFD 氣流粒子密度」滑桿，範圍 0.5×～4×；實際顯示 45～600 條氣流線（視畫面寬度），輸沙網格與沙量不受影響。此滑桿*不增加 CFD 流體求解網格的解析度*。
- 氣流示蹤線更集中在地表附近，便於觀察迎風坡與背風坡氣流；真實沙粒群仍由既有沙粒質量收支系統負責跳躍、碰撞與沉積。在 CFD 近景使沙粒點略易辨識。
- 退出 CFD、變更氣象風向及快轉時，保留原有的耦合邏輯、風場有效性檢查及相機狀態。
- CFD 密度拉桿設定可透過瀏覽器現有 localStorage 設定保留。

## 模型限制
這是 32×16×40 的 D3Q19 LBM 粗網格教學 CFD，水平格點約 7 m、垂直格點約 3.4 m。氣流視覺化貼合最新沙丘的*渲染地表*，不代表流體網格能解析全部 1.3 m 細節；地形顯著改變必須重算。流線是無質量的流體示蹤點而不是撞擊地面的沙粒；現有的沙點才是會發生跳躍與沉積的沙粒群。此模型沒有經過現地或風洞 CFD 驗證，不可用於真實工程預測。

HTML 仍使用原本程式的 Open-Meteo 資料與 GA4 掛載條件；請依原資料使用條款部署。
