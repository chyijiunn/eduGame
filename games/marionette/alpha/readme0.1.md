# Marionette Designer v0.1

這是一個用來規劃懸絲偶木料尺寸、切割排列與立體組裝的互動工具。

## 畫面四區

1. **左上：Front / Side** － 調整正視與側視尺寸。
2. **右上：切割排列** － 把所有木料方塊排進 100 mm 寬的切割區。
3. **左下：材料表** － 直接輸入高度 H、寬度 W、厚度 D。
4. **右下：3D** － 查看組裝後比例與手腳動作。

## Front / Side 怎麼改尺寸

- 點選方塊後，拖曳方塊的邊或角落。
- Front 改的是 **寬度 W + 高度 H**。
- Side 改的是 **厚度 D + 高度 H**。
- 同一個零件會自動同步，左右手、左右腳也會一起更新。
- 放開後，零件會重新依人體中軸排列。

## 三個按鈕

- **↕**：切換 3 mm 關節 gap。Head → Neck → Torso 仍維持 Neck 上下各埋入 5 mm。
- **▦**：把右上所有切割方塊重新緊湊排列。
- **A4**：以 1:1 真實尺寸列印 Front / Side，輸出固定使用 no gap。列印時請選 **100% / Actual size**，不要使用 **Fit to page**。

## 切割排列

- 材料區固定寬 **100 mm**，高度可以一直往下延伸。
- 每個零件以代號顯示；成對零件會放兩塊。
- 可以直接拖曳排列位置。尺寸改變後，方塊大小會同步。
- 按 **▦** 可以重新自動排列。

## 材料表

- **H**：高度
- **W**：正視寬度
- **D**：側視厚度
- 改任何數字，Front、Side、切割圖與 3D 都會一起更新。

## 3D 操作

### 電腦

- 左鍵拖曳背景：旋轉視角。
- 滾輪：縮放。
- 點到手或腳再拖曳：改變手腳擺動角度。

### 手機 / 平板

- 單指在空白處水平拖曳：水平旋轉視角。
- 單指拖曳手或腳：調整動作。
- 雙指：縮放並移動畫面。

沒有操作時，手腳會有很小的待機擺動；左右腳的節奏相反，模擬走路感。
