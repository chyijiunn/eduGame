- **H**：高度
- **W**：Front view 寬度
- **D**：Side view 厚度
- 修改數字後 Front、Side、切割排列和 3D 都會一起更新。
- 可拖曳 Front / Side 方塊的邊或角。
  - Front：改變 H / W。
  - Side：改變 H / D。
- 左右手和左右腳使用同一組材料尺寸。
## 按鈕
1. **↕**：3 mm gap 開 / 關。Head → Neck → Torso 仍維持 Neck 上下各埋入 5 mm。
2. **▦**：重新把所有材料緊密排列到 100 mm 寬切割區。
3. **A4↓**：直接下載 A4 PDF，不會開啟印表機。PDF 固定採 **no gap**，並用 1:1 真實尺寸繪製 Front / Side。
4. **3D**：開啟浮動 3D 視窗。只保留水平旋轉；點浮動視窗外面即可關閉。
## 切割排列

- 寬度固定 **100 mm**。
- 材料間不保留間隔；邊線可共用／重疊約 1 px。
- 每一塊材料都顯示代號與 **高度 × 寬度**，單位為 mm。
- 手、腳等成對零件會直接出現兩塊，不另外標左右。
- 可以用滑鼠或觸控拖曳材料方塊。
- 按 **▦** 可恢復自動緊密排列。

## 3D

3D 使用目前資料即時生成站立模型。
- 電腦：按住滑鼠左鍵左右拖曳。
- 手機／平板：單指左右拖曳。
- 只會沿垂直軸做水平旋轉，不提供上下旋轉、縮放或肢體拖曳。

## A4 PDF
- 按 **A4↓** 後直接下載 PDF。
- PDF 為 A4 單頁。
- Front / Side 使用 **no gap** 組裝狀態。
- 幾何尺寸以 1 mm 對應 PDF 內實際 1 mm 建立。
- 圖面內以材料代號標示，底部列出部位名稱與 H / W / D 尺寸。
