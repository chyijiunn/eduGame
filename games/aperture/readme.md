# 阿富汗相機光圈量測工具（手機網頁版）

這是一個可在手機瀏覽器使用的光圈量測頁面。流程是：先拍「全開光圈」做校準，再反覆拍「縮小後光圈」計算等效光圈（f-number）。

## 使用前準備
1. **發光平板背光**：用描圖板/平板燈/均勻發光面板作為背光來源。
2. **把光圈放在鏡頭後方、讓背光從後面透出**，孔洞應該是畫面中**最亮**的一塊。
3. 盡量降低環境反光（可在鏡頭前加黑紙圈/遮光筒）。

## 操作流程
1. 進入頁面後，輸入：
   - **鏡片直徑 D（mm）**：最大有效通光口徑（預設 27）
   - **焦距 f（mm）**：預設 150
2. 按 **開始** 開啟相機（請允許相機權限）。
3. **光圈全開**、背光打開後，按 **拍第一張（全開校準）**：
   - 系統會找出中心亮區（全開孔洞），建立基準面積 A0 與對位模板。
4. 調整到你想要的光圈後，按 **拍第二張（計算）**：
   - 系統會計算亮區面積 A1，換算等效光圈。
5. 你可以反覆調整光圈並多次按 **拍第二張（計算）**，不需要重拍第一張。
6. 若更換鏡片、距離或背光條件，按 **重新校準** 再拍一次全開。

## 建議檔位（阿富汗相機常用）
建議以 **f/5.6、f/8、f/11、f/16、f/22** 作為手工遮擋/光圈設定的目標檔位。本工具會顯示「最接近的檔位」。

## 常見失敗原因與解法
- **孔洞過曝（亮到邊緣糊掉）**：面積會偏大  
  → 降低背光亮度、稍微拉遠、避免直射反光。
- **環境反光太多**：會出現假亮斑  
  → 用遮光筒/黑紙圈，讓孔洞成為最亮區域。
- **孔洞沒有落在 ROI（中央 80%）**：抓不到或算錯  
  → 依照半透明模板與準星把孔洞對準中心再拍。
- **背光不均**：閾值分割不穩  
  → 把孔洞對準背光最均勻的區域，或換更均勻的光源。
