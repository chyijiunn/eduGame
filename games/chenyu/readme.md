
# 成語尋墨小遊戲 說明（readme.md）

## 🎮 遊戲目標
在 7×7（共 49 個字）字盤中，找出系統隨機挑選的 **三個四字成語**。  
每局的三個成語皆隨機抽取，並隱藏散布於棋盤中。

---

## 🕹️ 遊戲操作方式

### 1. 點擊字格選字
- 點擊一個格子即可選取該字。
- 最多可同時選取 **四個字**。
- 選滿四格後，系統會自動判斷是否為成語。

### 2. 選字判定規則
當你完成四字選取後：

| 選取結果 | 遊戲行為 |
|---------|---------|
| ✔ 正確：為本局三個目標成語之一 | 設為綠色，紀錄為已找到 |
| ☑ 是成語，但不是本局目標 | 顯示提示訊息，不視為完成任務 |
| ✘ 不是常見成語 | 提示錯誤，可重新嘗試 |

⚠ 字的位置 **不必在同一行、同一列或斜線**，只要正確四個字依照成語順序點擊即可。

---

## 💡 提示系統（共三次）
按下「提示」可取得線索：

| 第幾次提示 | 顯示內容 |
|-----------|-----------|
| 第一次 | 顯示【第一個成語】的首字與末字 |
| 第二次 | 顯示【第二個成語】的首字與末字 |
| 第三次 | 顯示【第三個成語】的首字與末字 |

例：  
若成語是「一見鍾情」 → 顯示為 **一＿＿情**

提示用完後不會結束遊戲，只是無法再取得新提示。

---

## ⏱ 計時
- 頁面載入後即自動開始計時。
- 當三個目標成語皆被找到時：
  - 計時停止
  - 顯示本局耗時
  - 遊戲結束（按鈕停用）

---

## 🔁 重新洗牌
按下「重新洗牌」會：
- 重抽三個新成語
- 重新分配字盤
- 清空提示與紀錄
- 重設計時
