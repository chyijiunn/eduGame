成雲機制｜參數說明與雲族對照

一、主要參數是什麼意思？

  • 地表露點 Td：地面空氣冷卻到何溫度會達到飽和。
    與地表溫度 T 的差值 T−Td 稱為「露點差」，影響雲底高度 LCL。模型近似：LCL ≈ 125 × (T − Td) m；露點差愈小 → 雲底愈低。
  • 環境遞減率 ELR（°C/km）：環境氣溫隨高度降低的速率。與乾絕熱 9.8、濕絕熱約 6 比較可判別穩定度：
    • ELR > 9.8 → 絕對不穩定：對流旺，易長高塔狀雲。
    • 6 ≤ ELR ≤ 9.8 → 條件不穩定：濕潤時對流易啟動。
    • ELR < 6 → 穩定：易出層狀雲或無明顯對流。
  • 上層濕度 RHhigh、中層濕度 RHmid：分別代表約 5–12 km、2–7 km 的相對濕度。本模型常用門檻：70% 以上易生成對應高度的雲；85% 以上可能成片。
  • 垂直風切（0–3 級）：高度改變時風速/風向的差異。
    級數愈高，積雨雲頂部越傾斜並形成鐵砧；也較容易將高冰晶吹散成卷雲/卷層雲。
  • 抬升機制：
    日間對流
    地形抬升
    鋒面抬升
    • 日間對流：地面增溫→氣塊上升；易產生積雲、條件佳時發展為積雨雲。
    • 地形抬升：迎風坡氣流被迫上升；常見層雲/層積雲、高層雲。
    • 鋒面抬升：暖/冷空氣交界的大尺度上升；常見高層雲、雨層雲、卷層雲。

二、參數如何影響雲族？（對照速查）

雲族（中/英）典型高度成因/條件降水
積雲 cumulus低（<2 km）小露點差、ELR ≥ 6；對流通常無或局部微雨
積雨雲 cumulonimbus低起→高頂露點差小、ELR 大、RHmid/high 足、風切中–大陣雨/雷雨
層雲 stratus低近地面飽和、ELR 小（穩定）、輕微抬升毛毛雨/霧滴
層積雲 stratocumulus低淺層混合作用、逆溫上蓋、ELR 中局部零星
高積雲 altocumulus中（2–7 km）RHmid 中–高；波動/弱不穩通常無
高層雲 altostratus中鋒面/地形抬升；RHmid 高、ELR 小–中可有持續小雨
雨層雲 nimbostratus中（可伸至低）大尺度抬升、RHmid 很高、ELR 小（穩定）持續性降雨
卷雲 cirrus高（5–12 km）RHhigh 中；常為對流雲頂外流無
卷積雲 cirrocumulus高RHhigh 高；高層小對流或波動無
卷層雲 cirrostratus高RHhigh 很高；鋒面前沿薄幕無（可見暈）

提示：T−Td 越小 → LCL 越低；ELR 越大 → 越有利對流；RHmid/high 決定中/高雲是否成片；風切影響雲塔傾斜與高雲外流。

三、如何用滑桿做探究？

  1. 固定 抬升機制＝日間對流，逐步減少露點差（拉高 Td）：觀察積雲 → 積雨雲的轉變與 LCL 變化。
  2. 固定 T、Td，改變 ELR：從穩定（層狀雲）到不穩定（對流雲）的過程。
  3. 固定低層條件，提升 RHhigh 或 RHmid：對比卷雲/卷層雲與高層/雨層雲出現的門檻。
  4. 在對流條件下增加 風切：觀察鐵砧與高雲外流的變化。
