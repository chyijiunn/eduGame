編輯器
常見編輯窗約為導引序列 第4–8 位（自 PAM 遠端算起）。下方會高亮可改寫的鹼基。
Prime editing 以導引 RNA 攜帶「反轉錄模板」在目標位置進行小片段改寫，不需產生 DSB。此處提供概念示意。
③ 步驟說明（通用繁中；括號附英）
  1. NHEJ 敲除（non-homologous end joining, NHEJ）：剪開→細胞自行黏回，常出現小插缺（insertion/deletion, indel），容易讓基因失效。
  2. HDR 敲入（homology-directed repair, HDR）：同時給「修補模板」（donor DNA / repair template），讓細胞按模板插入/替換（knock-in / replacement）。
  3. Base Editing（base editing）：不做雙股斷裂（double-strand break, DSB），只改單一鹼基（如 A→G：ABE；C→T：CBE）。
  4. Prime Editing（prime editing）：不需雙股斷裂，使用含反轉錄模板（reverse transcriptase template）的 pegRNA 在目標位點進行小幅改寫（插入/刪除/替換少數鹼基）。
