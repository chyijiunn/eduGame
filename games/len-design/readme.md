
# 非球面平凸透鏡設計器 v0.24

單一 HTML 工具，可設定口徑、焦距、折射率、圓錐常數與多項式係數（A4/A6/A8），即時顯示橫剖面、輸出 **實心 STL**、並提供「薄透鏡」成像模擬（可拖曳物距、屏幕、支援滾輪/雙指縮放與平移）。

## 使用方法
1. 開啟 `asphere_designer_v0_24.html`（支援離線）。
2. 左欄設定：
   - **CA** 清孔徑直徑（mm）
   - **EFL** 目標焦距（mm）
   - **n** 折射率（UV 光膠可取 1.520）
   - **厚度模式**：ET（邊緣厚度）或 CT（中心厚度）。若選 ET，系統自動以 `CT = ET + zEdge`。
   - **K** 圓錐常數（預設 -1 拋物面）
   - **A4/A6/A8** 非球多項式係數（UI 以縮放單位呈現；計算內部使用 mm 量綱）
3. 右側「設計視圖」：
   - 藍色：非球前表面；綠色：後平面；黃色：**ET** 標示；青色：**CA** 標示。
4. 匯出：
   - **下載 CSV**：`r,z` 剖面座標（mm）。
   - **下載實心 STL**：預設 Binary。網格品質與徑向弦高可調。輸出為**封閉、同向法線、含外周立壁+後平面圓盤+前表 apex 扇形**之實體。
5. **模擬成像**：按「模擬成像」切換；可拖曳物體（左側圓點）與屏幕位置（黃色直線），顯示 `u`（m）、`v`（mm）、`f`（mm）、倍率 `m`。支援滾輪/雙指縮放、拖曳平移。

## 非球面計算（前表）
採軸對稱非球式：

- 曲率 `c = (n - 1)/EFL`（平凸、後表面為平面假設）。
- 下陷量（sag）
```
z(r) =  c r^2 / (1 + sqrt(1 - (1+K) c^2 r^2)) + A4 r^4 + A6 r^6 + A8 r^8
```
- `r` 單位 mm；`A4/A6/A8` 內部使用 mm 量綱（UI 顯示為縮放後的係數）。
- 邊緣弧高 `zEdge = z(r_max)`，其中 `r_max = CA/2`。
- 厚度：
  - ET 模式：`CT = ET + zEdge`；本工具強制 `ET ≥ 0.5 mm` 以避免切片器將面合併視為共面。
  - CT 模式：由使用者直接指定。

## STL 幾何（保證實心）
- 前表面：apex 單點 + 環向剖分（三角扇 + 條帶）。
- 後表面：位於 `z = CT` 的圓盤（中心扇形）。
- 外周立壁：連接 `(r_max, zEdge)` 與 `(r_max, CT)`。
- 統一三角形方向（外法線一致）、無退化面、無未閉合邊界。

> 若切片仍顯示為「空心」，請檢查：
> 1. 未啟用 Hollow / 挖空；
> 2. `ET ≥ 0.5 mm`；
> 3. 使用 Repair（ChiTu/UVtools）一次；
> 4. 檔案單位為 **mm**（導入後直徑應約 CA）。

## 注意
- 本模擬使用**薄透鏡近似**做教學互動；高數值孔徑或厚透鏡需光線追跡才準確。
- STL 單位為 **mm**；匯入切片器時確認縮放未被改動。
