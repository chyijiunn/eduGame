# 紅巨星救援計畫（Solar Rescue）— 說明

這份說明會在遊戲內按「**遊戲說明 📖**」讀取並顯示。

---

## ▶ 遊玩重點（拉弓式發射）
- **按下**：發射點
- **往後拉**：速度大小與方向（方向取反）
- **放開**：發射小星艦
- 可**多重發射**；能源：發射 -2、救援 +10，=0 失敗。

## ⚙️ 物理與行星差異
- 引力參數：`mu = MU_SCALE * g * R^2`
- 近地軟化避免暴衝：`a = mu / (r^2 + (kR)^2)`
- 未載人時有入軌輔助（切線化 + 圓軌速度靠攏）；載人後啟動推進器可逃逸。
- 不同行星具不同 `g`、半徑 `R`、大氣阻力、入軌輔助強度與物種組合。

## 🛰️ 軌道類型（以比機械能判定）
- 橢圓：`ε < 0`（束縛）
- 拋物線：`ε ≈ 0`（臨界）
- 雙曲線：`ε > 0`（逃逸）

---

## 🔧 設定面板（倍率）
可在「⚙️ 設定」即時調整重力/阻力/軟化/入軌輔助/向心抑制、救援後推進與模式、子步進。  
這些是**全域倍率**，不會抹平各行星原始差異。
